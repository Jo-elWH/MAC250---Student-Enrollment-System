# MAC250 - Student Enrollment System

This Database App is based on the basic information needed for a Schools Database. 
These entities include Teachers, Students, Courses and enrollments


## Features
- Displaying, updating, deleting and adding of students, teachers and courses



## Installation
I used MySQL and Python to build this app. 
MySQL Workstation and server need to be installed and your local server has to be running.
To succesfully run this app you will also need to install mysql-connector-python.

  pip install flask mysql-connector-python

The above command can be run in console.

You will also have to open up the app.py file in your favourite editor and add your local servers root pass
on line 31 under "DB_CONFIG"



## Usage
Once everything is install and running, double click on the python file and goto this address in your browswer
http://127.0.0.1:5000/
